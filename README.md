# 💬 (RE)Sources Relationnelles

**Plateforme citoyenne de ressources relationnelles** créée dans le cadre d'un projet pédagogique au CESI.  
Ce projet vise à proposer des outils et contenus pour renforcer les liens sociaux et familiaux des citoyens.

---

## 🧠 Contexte

Le projet a été imaginé comme une commande fictive du **Ministère des Solidarités et de la Santé**.  
L’objectif est de concevoir une application web permettant aux citoyens d’accéder à des ressources relationnelles, de partager du contenu, et d’échanger autour de ces thématiques.

---

## 🎯 Objectifs

- Proposer des ressources relationnelles (articles, jeux, activités…)
- Permettre aux utilisateurs de créer et partager leurs propres ressources
- Offrir un espace d’échange commenté et modéré
- Suivre la progression personnelle des utilisateurs
- Fournir un espace d’administration et des statistiques

---

## 🛠️ Fonctionnalités principales

- 🔍 Recherche et filtrage de ressources
- 👤 Gestion des utilisateurs (citoyens, modérateurs, admins)
- 📝 Création de contenu par les utilisateurs
- 💬 Commentaires et modération
- 📊 Tableau de bord personnel & statistiques
- 🛡️ Respect des normes RGPD et d’accessibilité (RGAA)

---



## 🚀 Installation

```bash
# Clone le repo
git clone https://github.com/naelalaji/ressourcesRelationnelles.git

# Installation des dépendances
cd backend
npm install

cd ../frontend
npm install

# Lancement du serveur de dev
cd backend
npm run dev
```
